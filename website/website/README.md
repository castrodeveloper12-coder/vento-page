# Vento - Documentos Legales Website

Este directorio contiene los documentos legales de la aplicación Vento en formato web.

## 📋 Contenido

- **index.html**: Página principal con política de privacidad, términos y condiciones, y información de contacto
- **style.css**: Estilos para la página web

## 🌐 Despliegue

Para desplegar este sitio web, puedes usar cualquiera de estas opciones:

### 1. GitHub Pages (Recomendado)
1. Subir estos archivos a un repositorio de GitHub
2. Habilitar GitHub Pages en la configuración del repositorio
3. La URL será: `https://tu-usuario.github.io/tu-repositorio/website/`

### 2. Netlify
1. Arrastrar la carpeta `website` a Netlify
2. Obtendrás una URL automática

### 3. Vercel
1. Conectar el repositorio con Vercel
2. Configurar la carpeta `website` como directorio de publicación

## 📝 Uso en Google Play Console

Una vez desplegado, usa la URL en:
- **Política de Privacidad**: En la configuración de la app
- **Términos y Condiciones**: Como referencia en el formulario de declaración de permisos
- **Información de Contacto**: Para soporte al usuario

## 🔄 Actualizaciones

Cuando actualices los términos o política de privacidad:
1. Modifica `TERMS_AND_CONDITIONS.md` en la raíz del proyecto
2. Actualiza `index.html` con los nuevos contenidos
3. Recompila el AAB con los cambios
4. Redespliega el sitio web
