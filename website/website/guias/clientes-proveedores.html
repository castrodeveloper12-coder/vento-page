1) Listas y búsqueda

Listado

  • Pestañas: Clientes / Proveedores
  • Buscador por nombre/identificación
  • Botón + para crear nuevo
Tip: usa nombres consistentes y datos de contacto para reportes.

2) Crear/editar

Formulario

  • Nombre y datos de contacto
  • Notas (opcional)
  • Botón Guardar
Nota: para clientes podrás ver historial de compras; para proveedores, productos asociados.

3) Detalle y estadísticas

Detalle

  • Historial (compras o productos vinculados)
  • Métricas: totales, últimos movimientos
  • Acciones rápidas (editar/eliminar)
Consejo: mantiene actualizados los datos para aprovechar filtros y métricas.

4) Errores comunes

  • Datos de contacto vacíos: no es obligatorio, pero mejora reportes.
  • Duplicados: busca antes de crear para evitar registros repetidos.
