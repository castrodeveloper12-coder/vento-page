1) Activar crédito

Detalle del Cliente

  • Tarjeta “Crédito del Cliente”
  • Switch para activar
  • Botón “Configurar”
Nota: define límite y, opcional, interés simple/compuesto.

2) Venta a crédito

Método de pago

  • Elige “Crédito” (requiere cliente con crédito activo)
  • Validación de cupo disponible
  • Registro en credit_ledger
Importante: si el total supera el disponible, no permite continuar.

3) Registrar abono

Abono

  • Monto del pago
  • Asocia a sesión de caja si está abierta
  • Actualiza balance en tiempo real
Tip: usa notas para registrar referencia del pago.

4) Errores comunes

  • Intentar crédito sin cliente: selecciona o crea un cliente primero.
  • Abono mayor al saldo: valida el monto antes de confirmar.
