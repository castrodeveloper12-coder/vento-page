1) Crear producto

Formulario de Producto

  • Nombre, precio base y categoría
  • IVA específico opcional (tasa + tipo: incluido/excluido/sin IVA)
  • Imágenes del producto

Si no defines IVA específico, aplicará el IVA global del negocio.

Consejo: Usa una foto clara para mejorar la selección en ventas.

2) Configurar variantes

Variantes (Padre/Hijo)

  • Tipos: Color, Talla, etc.
  • Valores: Rojo, Azul; S, M, L…
  • Generación de combinaciones

Las variantes heredan categoría e IVA del padre (si no tienen configuración específica).

Nota: puedes editar stock y precio por variante si lo necesitas.

3) SKU híbrido

SKU

  • SKU sugerido automático
  • Totalmente editable para compatibilidad con códigos existentes
  • Único por variante

Puedes pegar un código de barras existente como SKU.

Tip: define un patrón claro: PARENT-COLOR-TALLA.

4) Detalle de producto

Detalle

  • Tarjeta de inventario y stock
  • Tarjeta de precios e IVA (ver configuración efectiva)
  • Listado de variantes

La tarjeta de IVA muestra si el producto usa IVA global o específico.

Consejo: ajusta stock de variantes desde esta vista.

5) Errores comunes

  • SKU duplicado: modifica el SKU antes de guardar.
  • Sin IVA válido: configura el IVA global si no usas IVA por producto.
  • Variantes sin valores: define al menos un valor por tipo para generar combinaciones.
