1) PIN

Configurar PIN

  • 4 dígitos (requerido)
  • No se respalda ni restaura
  • Se solicita al abrir la app
Nota: si restauras la BD en otro dispositivo, define un PIN nuevo.

2) Biometría

Autenticación biométrica

  • Huella digital / Face ID (si el dispositivo lo soporta)
  • Activación desde Ajustes
  • Fallback a PIN
Tip: activa biometría para ingresar más rápido.
