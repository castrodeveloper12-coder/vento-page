📋 Política de Privacidad de Vento

🎯 Resumen Ejecutivo: Vento es una aplicación de gestión de inventario híbrida (offline/online) que respeta completamente su privacidad. Sus datos se almacenan localmente y solo se sincronizan con Firebase Storage cuando usted lo autoriza y hay conexión a internet.

1. Información que Recopilamos

Vento funciona con un sistema híbrido offline/online:

  • Datos Locales: Información del negocio, inventario, ventas, gastos, clientes y proveedores se almacenan localmente en su dispositivo
  • Datos de Autenticación: Email y nombre para autenticación con Firebase Auth (opcional)
  • Fotografías: Imágenes de productos y recibos almacenadas localmente y sincronizadas con Firebase Storage cuando hay conexión

2. Sistema de Almacenamiento Híbrido

📱 Modo Offline:

  • Todos los datos se almacenan localmente en su dispositivo
  • La aplicación funciona completamente sin conexión a internet
  • Usted tiene control total sobre sus datos

☁️ Modo Online (Opcional):

  • Sincronización automática con Firebase Storage cuando hay conexión
  • Solo usuarios autenticados pueden acceder a sus datos en la nube
  • Segregación completa por usuario - nadie más puede ver sus datos
  • Limpieza automática de archivos locales después de sincronizar

3. Permisos de Cámara (android.permission.CAMERA)

Solicitamos el permiso de cámara únicamente para:

  • Fotografía de Productos: Capturar imágenes para facilitar la identificación visual en el inventario
  • Documentación de Gastos: Fotografiar recibos y comprobantes para registro de gastos
  • Escaneo de Códigos de Barras: Identificación rápida de productos

⚠️ Importante: El uso de la cámara es completamente opcional. La aplicación funciona perfectamente sin permisos de cámara.

4. Protección de Datos y Privacidad

  • Sin Terceros: No compartimos información con terceros no autorizados
  • Sin Análisis: No recopilamos datos de uso para análisis
  • Sin Tracking: No rastreamos su actividad personal
  • Cifrado: Transmisión segura HTTPS cuando se sincroniza con Firebase
  • Acceso Controlado: Solo usted puede acceder a sus datos mediante autenticación

5. Publicidad (Versión Gratuita)

La versión gratuita utiliza Google AdMob:

  • Anuncios no intrusivos en la parte inferior de la pantalla
  • Control de frecuencia para no afectar la experiencia
  • Solo datos anónimos para personalización
  • Puede desactivar la personalización desde configuración de AdMob
  • Sin publicidad para usuarios premium

6. Seguridad

  • PIN de Seguridad: 4 dígitos configurables
  • Autenticación Biométrica: Huella digital y Face ID (opcional)
  • Almacenamiento Seguro: Datos encriptados localmente
  • Respaldo Seguro: Firebase Storage con reglas de seguridad
